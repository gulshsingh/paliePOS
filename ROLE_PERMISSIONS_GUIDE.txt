PART 2: JO PERMISSIONS ABHI NAHI BANI HAIN (NEW CREATION REQUIRED)
================================================================================

Aapke backend schema me Restaurant POS ke yeh 3 important actions MISSING hain.
Backend team ko yeh 3 nayi permission keys create karni padengi:

1. 'orders.apply_discount' (Boolean)
   * Kahan lagega: POS Billing screen par discount dena (% ya flat amount).
   * Kyun chahiye: Waiter aur Cashier bina manager ki permission ke discount na de sake.
   * Role assignment:
     - admin: true
     - manager: true
     - cashier: false (ya limited)
     - waiter: false

2. 'orders.cancel' (Boolean)
   * Kahan lagega: Kitchen me KOT jane ke baad order cancel/void karna.
   * Kyun chahiye: Chori rokne ke liye. Waiter bina manager ke order cancel na kar sake.
   * Role assignment:
     - admin: true
     - manager: true
     - cashier: false
     - waiter: false

3. 'payments.refund' (Boolean)
   * Kahan lagega: Paid bill ka paisa wapas karna (Refund / Reversal).
   * Kyun chahiye: Cashier bina manager/admin ke cash drawer se refund na nikal sake.
   * Role assignment:
     - admin: true
     - manager: true
     - cashier: false
     - waiter: false
